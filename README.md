## Fundamentos de programación
Apartado para añadir la descripción a los proyectos que sean añadidos de la materia fundamentos de programación
Actividades:
semana1:
1. Actividad 1: En este código se realizo una calculadora de tiempo, donde la persona introduce cuantas horas le dedica a cada tipo de media digital, una vez que el código tiene los datos, suma las horas y saca el porcentaje de horas al día.
2. Ejercicios Extras sem1: En estos ejercicios se practico el uso de input para poder meter diferentes datos acorde al usuario.

3. Actividad 2: En este código se hizo un sistema de cobro para un museo, en el que se introducía con un ciclo for el numero de personas y luego la edad de estas, por ultimo se elije que tipo es para saber si aplica algún descuento especial, para lograr que no pongan datos indebidos, se uso un ciclo while para invalidar el poner datos erróneos, finalmente se juntan todos los datos en una tabla, poniendo la persona, el costo de su boleto y el descuento aplicado.
4. Ejercicios Extras sem2: Con estos códigos se practico el uso de ciclos while y ciclos for.
